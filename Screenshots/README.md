# OLA Booking Analysis — Dashboard Insights

This folder contains screenshots from the Power BI dashboard created using 100,000+ OLA booking records.

## Dashboard Analysis

### 1. Overall Dashboard
Provides an overview of booking volume, successful rides, cancellations, revenue, vehicle types, and ratings.

**Key Finding:** Provides a high-level view of overall OLA booking performance.

### 2.Vehicle Type Analysis
Analyzes booking volume across vehicle types and booking statuses.

**Key Finding:** Helps identify the vehicle categories contributing most to ride demand.

### 3. Cancellation Analysis
Analyzes customer and driver cancellations.

**Key Finding:** Highlights major cancellation patterns and their impact on successful bookings.

### 4. Rating Analysis
Compares customer and driver ratings across vehicle types.

**Key Finding:** Shows differences in customer and driver service ratings.

### 5. Revenue Analysis
Analyzes revenue across different booking and vehicle categories.

**Key Finding:** Identifies the major contributors to overall revenue.
